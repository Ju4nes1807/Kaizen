> Pequeños pasos. Cambios que permanecen.

**Kaizen** es una aplicación web enfocada en ayudar a las personas a mejorar sus rutinas diarias, consolidar hábitos positivos y transformar de manera gradual aquellos comportamientos que desean cambiar.

El proyecto toma como base el principio japonés de mejora continua: avances pequeños, sostenibles y repetidos en el tiempo. Kaizen no busca que el usuario sea perfecto; busca que pueda volver a intentarlo, aprender y continuar.

## Problema que aborda

Muchas personas comienzan cambios personales con objetivos demasiado grandes, métodos rígidos o expectativas poco realistas. Esto puede generar frustración y abandono ante el primer incumplimiento.

Kaizen propone un enfoque correctivo y constructivo: reconocer los hábitos actuales, reforzar los que aportan bienestar y crear acciones alternativas que ayuden a sustituir progresivamente los hábitos que alejan al usuario de sus objetivos.

## Propuesta de valor

- **Personalización desde el inicio:** el usuario podrá identificar sus hábitos actuales, tanto positivos como negativos.
- **Mejora gradual:** las acciones se plantean como pasos pequeños y alcanzables.
- **Rutinas antihábito:** en lugar de limitarse a prohibir una conducta, la aplicación plantea una secuencia alternativa que la bloquee o sustituya.
- **Progreso visible:** rachas, constancia, cumplimiento y evolución permitirán ver el avance a lo largo del tiempo.
- **Acompañamiento motivacional:** recordatorios y mensajes pensados para prevenir el abandono y ayudar a retomar el proceso después de una recaída.

## Diseño e identidad visual

La identidad de Kaizen combina una estética sobria, moderna y motivadora:

- **Negro profundo:** enfoque, contraste y concentración.
- **Carmesí:** energía, intención y acción.
- **Blanco cálido:** claridad y legibilidad.
- **Manrope y DM Sans:** tipografías limpias y contemporáneas para una experiencia digital clara.

El logo integra referencias al crecimiento, el equilibrio y la mejora continua, conectando la inspiración japonesa del nombre con el propósito de construir hábitos sostenibles.

## Alcance del MVP

El MVP de Kaizen estará enfocado en el ciclo principal del usuario:

1. Realizar un diagnóstico inicial de hábitos.
2. Crear uno o varios hábitos con una frecuencia definida.
3. Asociar, cuando aplique, una rutina alternativa a un hábito que se desea transformar.
4. Registrar el cumplimiento diario.
5. Consultar el progreso y las rachas.
6. Recibir mensajes o recordatorios que faciliten retomar la rutina.
